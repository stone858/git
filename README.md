# git

A minimal Python project skeleton.

## Requirements

- Python 3.12 or newer

## Setup

Create and activate a virtual environment:

```bash
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Install dependencies (if any):

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
python main.py --name Stone
```

## Configuration

Copy `.env.example` to `.env` and fill in your own values. The `.env` file is ignored by git and should never be committed.
